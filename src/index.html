急速与术士加算

Cᵢ = clamp((H + Xᵢ) / (100 + H + Xᵢ) + S, 0, 1)

先将通用与独立技能急速换算成冷却缩减，再加上术士比例 S。术士关闭时 S = 0。

Tᵢ = Bᵢ × (1 − Cᵢ)

基础 CD 返还

Fₐ = Bᵦ × M　 /　Fᵦ = Bₐ × M

大法师按释放技能的基础 CD 返还给另一技能。返还量不随释放技能的实际冷却变化。

Lᵢ = max(0, Tᵢ − Fᵢ)

最低成型急速

qᵢ = 1 − Fᵢ / Bᵢ − S

qᵢ ≤ 0 时需求为 0；qᵢ ≥ 1 时无有限解；其余为 max(0, 100qᵢ / (1 − qᵢ) − Xᵢ)。

H最低 = ceil(max(needₐ, needᵦ))
